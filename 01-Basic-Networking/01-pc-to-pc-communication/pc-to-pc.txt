PC-to-PC communication is the simplest form of networking where two PCs are directly connected using a cross-over cable. This lab demonstrates how to configure static IP addresses for two PCs and verify their connectivity using ping commands.

Path: 01-Basic-Networking/01-PC-to-PC-Communication/01-PC-to-PC.pkt  
Objective: Establish direct communication between two PCs using static IP addressing.

🛠️ Topology Overview  
| Device   | Quantity | Ports Used          |
|----------|----------|---------------------|
| PC       | 2        | FastEthernet0       |
| Cable    | 1        | Copper Cross-over   |

⚙️ IP Configuration  
| Device | IP Address      | Subnet Mask      | Default Gateway |
|--------|-----------------|------------------|-----------------|
| PC0    | 10.0.4.3        | 255.255.255.0    | (optional)      |
| PC1    | 10.0.4.4        | 255.255.255.0    | (optional)      |

🪛 Step-by-Step Instructions  
1. Launch Cisco Packet Tracer and open `01-PC-to-PC.pkt`.  
2. Add Devices:  
   - Drag 2 PCs to the workspace.  
3. Connect Devices:  
   - Use a Copper Cross-over cable.  
   - PC0 → PC1 (FastEthernet0 ports).  
4. Assign IP Addresses:  
   - On PC0:  
     - Go to **Desktop > IP Configuration**.  
     - Set IP: `10.0.4.3`, Subnet Mask: `255.255.255.0`.  
   - On PC1:  
     - Set IP: `10.0.4.4`, Subnet Mask: `255.255.255.0`.  

Verify using Command Prompt:  
- On PC0:  
  ```plaintext
  ping 10.0.4.4
```

💡 Learning Outcomes:
- Understand basic IP addressing.
- Learn how to use Packet Tracer for simulations.
- Get hands-on experience with PC-to-PC connectivity without a switch or router.
